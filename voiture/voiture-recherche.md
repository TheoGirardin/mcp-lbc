# Recherche Voiture d'Occasion

## Contexte

Je cherche une voiture d'occasion sur Le Bon Coin. La priorité absolue est le **rapport prix / kilométrage / fiabilité**, le type de voiture passe après. Usage : trajets variés mais **généralement courts (moins d'1h)**, pas de gros rouleur autoroutier.

L'idéal serait une voiture roulant à l'**éthanol (E85)** — soit d'origine flexfuel/superéthanol, soit un moteur essence à injection indirecte facilement convertible avec un boîtier homologué.

## Critères définis

### Obligatoire

- **Prix ≤ 8 000 €**
- **Kilométrage ≤ 150 000 km**
- **Localisation : 100 km autour de Reims (51100)** — couvre Châlons-en-Champagne, Épernay, Soissons, Laon, Charleville-Mézières, Sedan, Rethel, Vouziers, etc.
- **Carrosserie : citadine ou berline / compacte** (Clio, 208, Polo, Yaris / Golf, Mégane, 308, Octavia…)
- **Contrôle technique** valide, idéalement vierge ou avec uniquement des défauts mineurs

### Préférable

- **Essence** plutôt que diesel — les trajets courts (< 1h) encrassent les diesels modernes (FAP, vanne EGR, AdBlue)
- **Compatible éthanol E85** — soit flexfuel d'usine, soit moteur essence convertible (injection indirecte de préférence)
- **Faible kilométrage pour le prix** — privilégier les annonces sous la moyenne de leur catégorie
- **Carnet d'entretien suivi** + **courroie de distribution faite** (ou moteur à chaîne fiable)
- **Première ou deuxième main**, peu de propriétaires
- Boîte manuelle ou automatique : **indifférent** (mais éviter les boîtes auto réputées fragiles, cf. ci-dessous)

### À éviter absolument

- **Moteurs à problèmes connus** :
  - **1.2 PureTech (PSA)** essence à courroie de distribution dans l'huile → casse fréquente avant 100 000 km
  - **1.2 TCe / 1.3 TCe (Renault)** → surconsommation / perte d'huile, segments
  - **1.4 TSI EA111 (VW)** → tendeur de chaîne, surconsommation d'huile
  - **2.0 BlueHDi / 1.5 dCi** sur petits trajets → encrassement FAP/EGR
- **Compteur kilométrique douteux** (km incohérent avec l'usure, pas d'historique)
- **Véhicule sans contrôle technique** ou avec contre-visite non levée sur point de sécurité

### À éviter de préférence (négociable si très bonne affaire)

- **Diesel** en général (usage trajets courts)
- **Boîtes automatiques fragiles** : DSG7 sec (VW), EDC (Renault Getrag) première génération
- Véhicule très éloigné de Reims dans le rayon (frais et temps de déplacement)

## Stratégie d'achat retenue

Cibler des **moteurs essence atmosphériques simples et éprouvés**, peu coûteux à entretenir et bien adaptés à l'éthanol, plutôt qu'un véhicule récent à moteur downsizé turbo fragile. Mieux vaut une voiture un peu plus ancienne mais mécaniquement saine, avec un bon historique, qu'une voiture "clinquante" à moteur à risque.

L'objectif : prix bas + km raisonnable + **coût d'usage le plus bas possible** (carburant E85 ~0,70-0,90 €/L, entretien simple).

## Référence : moteurs essence fiables & compatibles éthanol

> Compatibilité E85 : les moteurs **essence à injection indirecte** se convertissent très bien (boîtier homologué ~700-1000 €, ou reprogrammation). Les injections directes turbo sont plus délicates.

- **Toyota** 1.0 / 1.33 / 1.5 (Yaris, Auris) — fiabilité de référence, chaîne de distribution
- **Honda** 1.2 / 1.4 i-VTEC (Jazz, Civic) — très fiable, atmosphérique
- **Dacia / Renault** 1.0 SCe / 0.9-1.0 TCe — versions **flexfuel d'usine** existantes (Sandero, Logan, Duster)
- **VW groupe** 1.4 / 1.6 MPI atmo (Polo, Golf, Fabia, Octavia) — robuste, bon pour E85
- **Ford** 1.25 / 1.4 / 1.6 Duratec (Fiesta, Focus) — simple et fiable
- **Renault** 1.2 16V / 1.6 16V atmo (Clio, Mégane anciennes générations)

## Référence : modèles flexfuel / superéthanol d'usine à privilégier

- Dacia Sandero / Logan / Duster **ECO-G / flexfuel**
- Ford Focus / C-Max **Flexifuel** (anciennes générations)
- Certaines Renault / Saab / Volvo **bioéthanol** d'époque

## Paramètres de recherche Le Bon Coin

- **Catégorie** : Voitures
- **Prix max** : 8 000 €
- **Kilométrage max** : 150 000 km
- **Localisation** : Reims (51100), rayon **100 km**
- **Carburant** : Essence (+ Bioéthanol / flexfuel si filtre dispo), Diesel uniquement si exception
- **Tri** : meilleures affaires (prix bas / km bas pour le modèle)
